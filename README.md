# ⛏️ Exodium (1.17.1)

> Un mod Minecraft inspiré des mécaniques emblématiques du serveur Paladium, développé pour la version **1.17.1** avec **Forge**.

---

## 📖 À propos

**Exodium** cherche à recréer ou à réinterpréter l'expérience de jeu unique du célèbre serveur moddé Paladium. Ce mod apporte des fonctionnalités de farm, de minerais moddés et d'objets uniques.

---

## ✨ Fonctionnalités principales

* 🟢 **Nouveaux Minerais :** Ajout de minerais inédits.
* 🎒 **Items Utilitaires :** Introduction d'objets spéciaux (marteaux de minage, deltaplane, etc.).
* ⚙️ **Blocs :** Blocs personnalisés pour la protection de base.

---

## 📥 Installation

1. Télécharge et installe **Forge** pour la version **1.17.1**.
2. Télécharge la dernière version d'**Exodium**.
3. Place le fichier `.jar` téléchargé dans le dossier `mods` de ton répertoire Minecraft (`.minecraft/mods`).
4. Lance ton jeu et amuse-toi !
